# Shopify Massage Theme

A high-conversion Shopify theme optimized for massage device products (neck massagers, fascia guns, etc.) based on Shopify's official Dawn theme.

## Features

- **Performance-First Design**: Built on Shopify's Dawn theme - HTML-first, minimal JavaScript
- **Conversion Optimized**: Clear CTAs, quick add-to-cart, trust signals for product sales
- **Mobile-Friendly**: Responsive design perfect for mobile shoppers
- **Online Store 2.0**: Full support for Shopify's latest theme features
- **Customizable**: Easy to modify colors, fonts, layouts through theme settings

## Installation

1. Clone this repository
2. Install Shopify CLI: https://shopify.dev/themes/tools/cli
3. Connect to your Shopify store: `shopify theme dev`
4. Open your store in a browser and start customizing

## Customization for Massage Products

### Product Page Optimization
- High-quality product images and video support
- Trust badges and certifications display
- Customer reviews section
- Related products recommendation

### Conversion Features
- Fast checkout process
- Product recommendations
- Limited stock indicators
- Customer testimonials

## Development

```bash
# Start development server
shopify theme dev

# Run theme checks
shopify theme check

# Build for production
shopify theme pull
```

## Based On

This theme is based on [Shopify's Dawn](https://github.com/Shopify/dawn) - Shopify's official open-source reference theme.
